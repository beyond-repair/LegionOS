# Open Questions (LegionOS v0.1)

1. **Founder Brain**
   - How do we balance autonomy and control without stifling innovation?
   - What fallback mechanisms exist if the LLM hallucinates a bad decision?

2. **Knowledge Graph**
   - How do we prevent data leakage between tenants while still enabling global insights?
   - How do we handle schema evolution as new business models emerge?

3. **Sandboxing**
   - What is the most secure way to allow agents to interact with third-party APIs?
   - How do we detect and mitigate malicious agents in real time?

4. **Scalability**
   - How do we ensure the system scales to 100K+ companies without performance degradation?
   - What is the cost structure for running this at scale?

These must be resolved or explicitly deferred with rationale before advancing past MVA Phase 2.
